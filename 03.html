1. CHAPTER 03 개요

Verilog HDL(베릴로그 HDL, 하드웨어 기술 언어)은 논리 게이트 수준의 모델링을 위해 미리 정의된 gate primitive(게이트 프리미티브, 기본 게이트 요소)를 제공한다. 이 프리미티브는 별도의 모듈 정의 없이 바로 사용할 수 있다.

기본 논리 게이트

and, nand, nor, or, xor, xnor

다출력 게이트

buf, not

3상태 게이트

bufif0, bufif1, notif0, notif1

기타 프리미티브

pull gate, MOS switch, bidirectional switch 등이 존재한다.

범위
이 장은 기본 논리 게이트 프리미티브를 이용한 하드웨어 설계를 중심으로 다루며, 스위치 수준 모델링은 합성용 셀 라이브러리 표현에 사용될 수 있다고 소개만 하고 상세히 다루지 않는다.

1.1 프리미티브 사용 위치

중요 문법
게이트 및 스위치 프리미티브는 모듈 몸체에서 사용한다. 이를 initial 또는 always 블록 내부에서는 사용할 수 없다고 설명한다.
module → 게이트 프리미티브 인스턴스 → endmodule

2. 3.1 기본 논리 게이트 프리미티브

게이트 수준 회로 모델링에는 and, nand, or, nor, xor, xnor를 사용할 수 있다. 이 기본 게이트들은 하나의 출력과 두 개 이상의 입력을 갖는다.

and
모든 입력이 1일 때 출력 1
nand
AND 결과의 반전
or
입력 중 하나 이상이 1이면 출력 1
nor
OR 결과의 반전
xor
입력의 배타적 OR
xnor
XOR 결과의 반전

2.1 기본 문법

primitive_gate_name [#(n1, n2)] [instance_name] (output, input1, input2, ...);
구성의미
primitive_gate_name and, nand, or 등 사용할 게이트 종류
#(n1,n2) 선택적인 전달지연. 첫 값은 상승지연, 둘째 값은 하강지연
instance_name 일반 인스턴스에서는 생략 가능. 프리미티브 배열에서는 필요
포트 순서 출력을 먼저 쓰고 그 뒤에 입력들을 나열
포트 연결 방법
기본 게이트 프리미티브는 하위모듈 인스턴스와 달리 순서에 의한 포트 매핑만 사용한다. 즉, .a(a) 같은 이름 기반 포트 연결은 사용하지 않는다.

2.2 게이트 인스턴스 예

nand U1 (out_nd2, a, b);
nor       (out_nr3, a, b, c);

and #2 U3 (out_and2, a, b);
xnor #(3, 4) U4 (out_xnor3, c, b, a);
#2
상승/하강 전달지연이 모두 2 time unit
#(3,4)
상승지연 3, 하강지연 4
지연 생략
default 전달지연 0
두 개의 지연 값과 x
두 지연 값이 지정된 경우 출력이 x로 변하는 지연은 두 값 중 작은 값으로 결정된다고 설명한다.

3. 게이트 프리미티브를 이용한 전가산기 모델링

전가산기(full adder, 풀 애더)를 기본 게이트 프리미티브로 직접 구성한다. 내부 연결선 s1, c1, c2가 회로도상의 실제 중간 신호선에 대응한다.

a,b →
XOR
→ s1 →
XOR + cin
→ sum
a,b →
AND
→ c1
s1,cin →
AND
→ c2
c1,c2 →
XOR
→ cout
코드 3-1
module full_adder_g (
    input  a,
    input  b,
    input  cin,
    output sum,
    output cout
);

wire s1, c1, c2;   // 1비트 내부 연결선

xor    (s1, a, b);
and    (c1, a, b);
and G3 (c2, s1, cin);
xor G4 (sum, s1, cin);
xor G5 (cout, c1, c2);

endmodule
CODE → 실제 회로
각 게이트 인스턴스는 함수 호출이 아니라 실제 논리 게이트 한 개를 회로에 배치하는 것과 같은 의미이다. 동일한 이름의 wire는 회로도에서 같은 물리적 연결선을 나타낸다.
cout에 XOR를 사용한 이유를 이해할 때
이 회로에서는 c1 = a & b와 c2 = (a ^ b) & cin이 동시에 1이 되는 입력 조합이 없으므로 두 신호를 XOR해도 전가산기의 carry 출력 기능을 만족한다.

4. 3.2 buf 게이트와 not 게이트 프리미티브

buf는 입력 논리값을 그대로 전달하는 디지털 버퍼이고, not은 입력을 반전시키는 인버터이다. 두 프리미티브 모두 입력은 하나이고 출력은 하나 이상을 가질 수 있다.

입력buf 출력not 출력
001
110
xxx
zxx

4.1 포트 순서

buf (output1, output2, ..., input);
not (output1, output2, ..., input);

출력이 여러 개라면 출력들을 먼저 나열하고, 마지막 포트 하나가 입력이 된다.

그림 3-4의 인스턴스 예
buf #(2, 1) bf1 (out_buf, in);

not #3 (out_inv, in);

buf bf2 (
    out1_buf, out2_buf, out3_buf,
    in
);

not (
    out1_inv, out2_inv,
    in
);
buf #(2,1)
상승지연 2, 하강지연 1
not #3
상승/하강지연 모두 3
지연 생략
default 지연 0

5. 3.3 3상태 버퍼 게이트 프리미티브

bufif0, bufif1, notif0, notif1는 3상태 드라이버(tri-state driver, 트라이스테이트 드라이버)를 모델링한다. 출력은 0, 1, z가 될 수 있다.

primitive (output, data, control);
output ← data + control
프리미티브제어가 활성일 때비활성일 때
bufif1data 그대로 출력z
bufif0control=0일 때 data 출력z
notif1data 반전 출력z
notif0control=0일 때 data 반전 출력z
H / L 상태
제어 또는 데이터가 x인 일부 조합에서는 출력이 0 또는 z일 수 있는 상태를 L, 1 또는 z일 수 있는 상태를 H로 표시한다.

5.1 3상태 게이트의 지연값

3상태 게이트에는 최대 세 개의 지연값을 지정할 수 있다.

지연 순서의미
첫 번째출력이 1로 천이하는 상승지연
두 번째출력이 0으로 천이하는 하강지연
세 번째출력이 z로 천이하는 턴-오프 지연
예시 3-1
bufif1 #(10, 12, 11) (out3, in, control);

bufif0 #(3, 5) U1 (out1, in, control);

notif0 #3 U3 (out2, in, control);

notif1 U4 (out4, in, control);
3개 지정

rise / fall / turn-off 각각 지정

2개 지정

rise / fall 지정, x 또는 z 관련 지연은 작은 값 사용

1개 지정

모든 출력 변화에 동일한 지연

생략

전달지연 0

6. 3.4 게이트 프리미티브 인스턴스의 배열

같은 형태의 게이트를 여러 개 반복할 때 인스턴스 이름 뒤에 범위를 지정하여 게이트 프리미티브 배열을 만들 수 있다.

gate_type instance_name [range] (ports...);

6.1 배열 범위

[n:m]으로 지정된 연속 범위에 따라 여러 인스턴스가 생성되며, 어느 한쪽이 반드시 0일 필요는 없고 오름차순/내림차순 모두 가능하다고 설명한다.

문법 오류 예
module invalid_array_example (
    input  [7:0] a,
    input  [7:0] b,
    output [7:0] y
);

// 문법 오류: 동일한 인스턴스 이름 I_nand를
// 분리된 두 배열 범위에 다시 사용
nand I_nand [0:3] (
    y[3:0], a[3:0], b[3:0]
),
     I_nand [4:7] (
    y[7:4], a[7:4], b[7:4]
);

endmodule

동일한 인스턴스 식별자 I_nand를 서로 분리된 두 인스턴스 배열 범위에 다시 사용했기 때문에 오류가 된다.

올바른 표현
module valid_array_example (
    input  [7:0] a,
    input  [7:0] b,
    output [7:0] y_all,
    output [7:0] y_split
);

// 하나의 연속 배열 범위
nand I_nand [0:7] (
    y_all, a, b
);

// 서로 다른 인스턴스 이름을 사용한 두 배열
nand x_nand [0:3] (
    y_split[3:0], a[3:0], b[3:0]
),
     y_nand [4:7] (
    y_split[7:4], a[7:4], b[7:4]
);

endmodule

6.2 4비트 2입력 NOR 게이트

코드 3-2: 배열 표현
module nor_gate_4b (
    input  [3:0] a,
    input  [3:0] b,
    output [3:0] y
);

nor U0 [3:0] (y, a, b);

endmodule
코드 3-3: 개별 인스턴스로 풀어쓴 표현
module nor_gate_4b_eq (
    input  [3:0] a,
    input  [3:0] b,
    output [3:0] y
);

nor U3 (y[3], a[3], b[3]);
nor U2 (y[2], a[2], b[2]);
nor U1 (y[1], a[1], b[1]);
nor U0 (y[0], a[0], b[0]);

endmodule
비트별로 풀어보면
nor U0 [3:0] (y, a, b);는 4개의 2입력 NOR 게이트를 병렬로 만든다. 즉, y[3:0]의 각 비트는 같은 인덱스의 a와 b를 입력으로 갖는다.

7. 3.5 게이트 지연과 net 지연

실제 하드웨어에서는 입력이 변한 순간 출력이 즉시 바뀌지 않는다. 이 전달 시간을 더 정확하게 표현하기 위해 게이트 지연(gate delay)과 net 지연(net delay)을 설명한다.

구분의미
게이트 지연 논리 게이트 입력 변화가 출력에 나타날 때까지의 전달지연
net 지연 net을 구동하는 구동자 값이 변한 뒤 실제 net 값이 갱신될 때까지의 지연

7.1 세 가지 전달지연

d1 : 상승지연
출력이 논리 1로 천이할 때의 지연
d2 : 하강지연
출력이 논리 0으로 천이할 때의 지연
d3 : 턴-오프 지연
출력이 z로 천이할 때의 지연
x로 천이할 때
세 값이 지정된 경우 x로 변하는 지연은 min(d1,d2,d3), 두 값만 지정된 경우에는 min(d1,d2)가 적용된다.

7.2 지연값 지정 예

and    #10         u0 (out, in1, in2);
nor    #(10, 12)   u1 (out, in1, in2);
bufif0 #(10,12,11) u3 (out, in, ctrl);
표현의미
#10모든 전달 변화에 동일한 지연 10
#(10,12)상승 10, 하강 12
#(10,12,11)상승 10, 하강 12, turn-off 11

7.3 전달지연 규칙

8. 지연이 포함된 3상태 출력 래치

코드 3-4는 not, nand, bufif1을 이용해 3상태 출력을 갖는 래치 회로를 구성한다. 각 게이트에는 서로 다른 전달지연이 지정되어 있다.

코드 3-4
module tri_latch (
    input  clock,
    input  data,
    input  enable,
    output qout,
    output qbout
);

tri qout, qbout;

not #5 u0 (ndata, data);

nand #(3,5)
    u1 (wa, data, clock),
    n3 (wb, ndata, clock);

nand #(12,15)
    u2 (q,  qb, wa),
    n5 (qb, q,  wb);

bufif1 #(3,7,13)
    u3 (qout,  q,  enable),
    u4 (qbout, qb, enable);

endmodule
동일 지연을 갖는 인스턴스 묶기
같은 프리미티브이면서 같은 지연값을 갖는 여러 게이트를 한 문장 안에 함께 인스턴스할 수 있음을 보여준다.
data → 입력 NAND 경로 → 교차결합 NAND 래치 → bufif1 → qout / qbout
경로별 전달지연
입력에서 출력까지의 전체 지연은 한 숫자로 고정되는 것이 아니라, 실제로 신호가 통과한 게이트 경로의 지연들이 누적되어 결정된다.

9. 관성지연

Verilog HDL의 게이트 지연에는 inertial delay(관성지연, 짧은 펄스를 걸러내는 지연 특성)가 기본적으로 적용된다. 입력 변화가 게이트 전달지연보다 짧게 유지되면 그 변화가 출력까지 전달되지 않을 수 있다.

코드 3-5
module inertial_delay_gate;

reg a, b;

and #30 (out, a, b);

initial begin
    a = 1'b0; b = 1'b0;

    #50 a = 1'b1; b = 1'b1;
    #50 a = 1'b0; b = 1'b0;
    #50 a = 1'b1; b = 1'b1;

    #20 b = 1'b0;

    #50;
end

endmodule

9.1 시간 흐름

t=0 → a=0, b=0 → out=0
t=50 → a=1, b=1 30ns 지연 out에 변화 반영
t=150 → a=1, b=1 20ns 후 b=0
입력 펄스
지연 30ns
입력 HIGH 유지시간은 20ns → 게이트 지연보다 짧음
출력
짧은 HIGH 펄스가 출력까지 전달되지 않음
핵심 예
150ns에서 170ns까지 b가 1을 유지하는 시간은 20ns인데, AND 게이트의 지연은 30ns이다. 따라서 이 20ns 폭의 입력 변화는 출력에 영향을 주지 못한다.
Simulation과 실제 FPGA 구분
이 절의 #30은 Verilog 시뮬레이션에서 게이트 전달지연을 표현하기 위한 모델이다. 실제 FPGA의 물리적 지연은 구현 후 Timing Analysis(타이밍 분석) 결과로 확인해야 하며, 소스의 # 지연값을 실제 FPGA 지연으로 그대로 간주하면 안 된다.

10. 최종 핵심 정리

항목핵심 내용
게이트 프리미티브미리 정의된 논리 게이트를 모듈 내부에 직접 인스턴스
포트 순서기본 게이트는 출력이 먼저, 그 뒤에 입력
인스턴스 이름일반 게이트는 생략 가능, 배열에서는 필요
기본 게이트and nand or nor xor xnor
buf / not입력 1개, 출력 1개 이상 가능
3상태 게이트bufif0/1, notif0/1, 출력 z 가능
프리미티브 배열같은 게이트 여러 개를 벡터처럼 반복 인스턴스
상승지연출력이 1로 바뀔 때의 전달지연
하강지연출력이 0으로 바뀔 때의 전달지연
턴-오프 지연출력이 z로 바뀔 때의 전달지연
