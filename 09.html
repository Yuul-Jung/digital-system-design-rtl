1. CHAPTER 09 전체 개요

7장에서는 사용자가 직접 정의하는 함수와 태스크를 다루었다. 이번 장에서는 Verilog HDL이 미리 제공하는 system task(시스템 태스크)와 system function(시스템 함수)를 다룬다.

표기 규칙
시스템 태스크와 시스템 함수는 모두 $ 기호로 시작한다. 예: $display, $monitor, $fopen, $finish, $time, $realtobits
디스플레이 처리

시뮬레이션 중 값과 메시지를 화면에 출력하여 디버깅한다.

파일 입출력

파일을 열고 닫거나, 결과를 저장하고 메모리 값을 파일에서 읽는다.

시뮬레이션 제어

시뮬레이션을 종료하거나 일시 중단한다.

자료형 변환

정수·실수·64비트 이진 표현 사이의 값을 변환한다.

Simulation 중심의 장
이 장의 많은 시스템 태스크는 실제 FPGA에 합성되는 기능을 만드는 구문이라기보다 테스트벤치와 시뮬레이션 디버깅 환경을 구성하기 위해 사용한다. 따라서 “시뮬레이션에서 무엇을 관찰·제어하는가?”를 중심으로 이해하는 것이 중요하다.

1.1 학습 목표

  • 파일처리용 시스템 태스크의 사용 방법 이해
  • 시뮬레이션 제어 시스템 태스크의 사용 방법 이해

3. 9.1 디스플레이 시스템 태스크

$display(list_of_arguments);
$write(list_of_arguments);
$monitor(list_of_arguments);
$strobe(list_of_arguments);
태스크핵심 동작
$display호출 시점의 값을 출력하고 자동 줄바꿈
$write호출 시점의 값을 출력하되 자동 줄바꿈 없음
$monitor인수 신호 값이 바뀔 때마다 자동 출력
$strobe현재 시간 단계의 끝에서 최종값 출력

3.1 진수별 전용 태스크

진수displaywritestrobemonitor
2진수$displayb$writeb$strobeb$monitorb
8진수$displayo$writeo$strobeo$monitoro
16진수$displayh$writeh$strobeh$monitorh
인수 없이 호출할 때
$display();는 줄바꿈을 출력하지만 $write();는 아무것도 출력하지 않는다.

6. $monitor · $monitoron · $monitoroff

$monitor는 인수로 지정된 신호 중 하나라도 값이 바뀌면 해당 시각의 값들을 자동으로 출력한다.

예시 9-1
initial begin
    $monitor(
        $time,
        "clock = %b reset = %b",
        clk,
        rst
    );
end
clk 또는 rst 변화→$monitor 자동 출력→현재 시간 + 값 확인
  • $monitoron → 모니터링 활성화
  • $monitoroff → 모니터링 비활성화
  • 기본 상태를 on으로 설명한다.

7. $strobe — 현재 시간 단계의 최종값

코드 9-4
module disp_strobe;
reg [7:0] a, b;

initial begin
    a = 8'h34;
    b = 8'h34;

    #10 b <= a + 1;

    $display("$display-1 : time=%0t a=%h b=%h", $time, a, b);
    $strobe ("$strobe-1  : time=%0t a=%h b=%h", $time, a, b);

    #5;

    $display("$display-2 : time=%0t a=%h b=%h", $time, a, b);
    $strobe ("$strobe-2  : time=%0t a=%h b=%h", $time, a, b);
end
endmodule
① t=10ns에서 nonblocking 할당 예약
b <= a + 1에 의해 b의 새 값 35(hex)가 같은 시간 단계의 갱신 시점에 예약된다.
② $display
호출 즉시 값을 읽으므로 b=34를 출력한다.
③ $strobe
현재 시간 단계 끝에서 최종값을 읽으므로 b=35를 출력한다.
Time resolution is 1 ps $display-1 : time=10000 a=34 b=34 $strobe-1 : time=10000 a=34 b=35 $display-2 : time=15000 a=34 b=35 $strobe-2 : time=15000 a=34 b=35

9. 파일 출력 — $fdisplay

코드 9-5
module file_fdisplay;
integer fd, n, result;

initial begin
    fd = $fopen("sum.dat", "w");

    if (fd == 0)
        $display("File open ERROR !!");

    result = 0;

    for (n = 0; n <= 10; n = n + 1) begin
        result = result + n;
        $fdisplay(fd, "n=%0d : Cumulative Sum = %0d", n, result);
    end

    $fclose(fd);
end
endmodule
$fopen→누적합 계산→$fdisplay→sum.dat→$fclose
n=1 : Cumulative Sum = 1 n=2 : Cumulative Sum = 3 n=3 : Cumulative Sum = 6 n=4 : Cumulative Sum = 10 n=5 : Cumulative Sum = 15 n=6 : Cumulative Sum = 21 n=7 : Cumulative Sum = 28 n=8 : Cumulative Sum = 36 n=9 : Cumulative Sum = 45 n=10 : Cumulative Sum = 55

10. $readmemb와 $readmemh

$readmemb("file_name", memory_name [, start_addr [, finish_addr]]);
$readmemh("file_name", memory_name [, start_addr [, finish_addr]]);
$readmemb2진수 데이터를 읽어 메모리에 로드
$readmemh16진수 데이터를 읽어 메모리에 로드
예시 9-2
reg [7:0] mem [1:256];

initial
    $readmemh("mem.data", mem);

initial
    $readmemh("mem.data", mem, 16);

initial
    $readmemh("mem.data", mem, 128, 1);
호출로드 범위
주소 미지정mem 시작 주소 1부터 순차 로드
시작주소 16주소 16부터 마지막 방향으로 로드
128, 1주소 128부터 1까지 역방향 로드
읽기 파일 내용
2진/16진 값 외에 x, z, 밑줄, 공백, 줄바꿈, 탭, 주석 등을 포함할 수 있다고 설명한다.

11. 9.3 시뮬레이션 제어 시스템 태스크

$finish[(n)];
$stop[(n)];
$finish시뮬레이션 종료 후 호스트 운영체제로 제어 반환
$stop시뮬레이션 일시 중단

11.1 진단 메시지 수준

0진단 메시지 출력 안 함
1시뮬레이션 시간과 위치 출력
2시간·위치 + 메모리·CPU 시간 출력
코드 9-6
module tb_ring_counter;
reg enable, reset, clk;
wire [7:0] count;

ring_counter U0_ring(enable, reset, clk, count);

initial begin
    clk = 1'b0;
    forever #20 clk = ~clk;
end

initial begin
    #5   reset = 0; enable = 0;
    #10  reset = 1;
    #20  reset = 0;
    #10  enable = 1;
    #100 enable = 0;
    #140 enable = 1;
    #600 $finish;
end
endmodule
합성 대상이 아님
$finish, $stop은 테스트벤치의 시뮬레이션 제어용으로 이해해야 한다.

12. 9.4 변환 시스템 함수

$rtoi(real_val)
$itor(int_val)
$realtobits(real_val)
$bitstoreal(bit_val)
함수동작
$rtoi실수 값을 정수형 값으로 변환
$itor정수 값을 실수 값으로 변환
$realtobits실수 값을 64비트 이진 표현으로 변환
$bitstoreal$realtobits의 역변환
$rtoi와 $round
$rtoi는 실수의 소수부를 0 방향으로 절삭한다. 가장 가까운 정수로 반올림할 때는 $round를 사용한다.
코드 9-7
module driver(output net_r);
real r_val;
wire [64:1] net_r = $realtobits(r_val);
endmodule

module receiver(input net_r);
wire [64:1] net_r;
real r_val2;

initial
    r_val2 = $bitstoreal(net_r);
endmodule
real r_val→ $realtobits64비트 net_r→ 포트 전달receiver→ $bitstorealreal r_val2
